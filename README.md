# Sr- 90 Radioactivity Data Analysis

A computational investigation of the distance dependence of Sr- 90 beta-particle count rates, combining experimental data analysis, mathematical modelling and Monte Carlo simulations.

## Project Overview

The project investigates how source- detector separation affects measured count rates, evaluating the limitations of the inverse- square model and the influence of finite source and detector geometry and air attenuation.

The analysis includes:
- Experimental data processing, Poisson counting statistics and uncertainty propagation.
- Fitting and comparison of five theoretical models.
- Extended comparison of 64 model configurations.
- Monte Carlo simulations of geometric acceptance and beta- particle transmission through air.
